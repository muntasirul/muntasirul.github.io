**Detection and Classification of Peripheral Blood Cells in Microscopic Images using Deep Learning**  
ICIICE 2026, Dubai — indexed in IEEE Xplore. Co-authored by N. M. Muntasirul Haque.

Developed a two-stage detection and classification pipeline using full-resolution microscopy images. Reported results:

## Local preview and GitHub Pages

The website uses static HTML, CSS, and vanilla JavaScript, with no build step. Its design includes:

- Midnight navy/light blue and light themes, system preference detection, and a saved manual choice.
- Locally hosted Outfit and Inter fonts, with licenses in `assets/fonts/`.
- A split hero with an optimized copy of the original portrait.
- Illustrated project covers, category filters, an education timeline, and distinct research/leadership sections.
- One-time hero entrances and scroll reveals, subtle hover effects, and reduced-motion support.
- Responsive keyboard-accessible navigation, native research disclosure, and direct email/copy-email actions.
- Static core content and links that remain available when JavaScript is disabled.

The project covers are concept illustrations, not actual application screenshots or model results. Clicking the email address opens the visitor's email application; there is no server-side form.

Run from this folder:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://localhost:8000`.

For GitHub Pages, publish these files from the configured publishing folder in the `muntasirul.github.io` repository. Keep `.nojekyll` and the CV PDF alongside `index.html`. No Node.js server or framework build is required. This local folder is not a Git checkout; the repository's publishing settings must be checked separately.
